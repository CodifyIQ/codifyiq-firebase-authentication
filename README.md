# CodifyIQ Firebase Authentication

[![License](https://img.shields.io/github/license/mashape/apistatus.svg)](https://opensource.org/licenses/mit)

Firebase-backed Google, Apple, and email/password sign-in for Flutter apps with multi-environment Firebase support.

See the [package README](codifyiq_firebase_authentication/README.md) for full documentation, setup instructions, and usage examples.

## Building with Maven

This project uses `exec-maven-plugin` to integrate Flutter into the Maven
lifecycle:

```bash
# Clean
mvn clean

# Resolve dependencies
mvn initialize

# Format code
mvn process-classes

# Publish to pub.dev
mvn deploy
```
